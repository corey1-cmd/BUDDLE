# buddle 디자인 시스템 (DESIGN_SYSTEM.md)

작성: 2026-06-12 · 적용 범위: `web/` 전 10페이지

## 방향: 버들 = 물가의 버드나무

이름 *버들*은 willow(버드나무)다. 사업계획서가 약속한 것은 "외로움을 줄이는
따뜻한 연결" — 차가운 'AI 컴패니언'도, 시끄러운 'SNS'도 아니다. 그래서 디자인
언어는 **고요한 종이 바탕 · 버들 잉크색 텍스트 · 행동에만 쓰는 단 하나의 버들
그린 액센트**다. 대담함은 한 곳(서명 요소)에만 쓰고 나머지는 전부 절제한다.

### 이전 디자인의 핵심 문제 — 메타포 충돌
구 디자인은 **증권 거래 단말(MTS)** 은유로 짜여 있었다: 종목=페르소나, 빨강/
파랑 등락률, "GLOBAL MARKET" 배너, 라벤더-핑크 6색 그라데이션. 이는 "화려함"의
문제가 아니라 **제품 본질과의 충돌**이었다 — 0.05초 신뢰가 트레이딩 앱 쪽으로
잘못 형성된다. 이번 작업은 단순 장식 제거가 아니라 메타포를 제품에 맞게 교정한
것이다(빨강/파랑 등락 → 제거, 라벤더 → 버들 그린 단일 액센트).

## 토큰 시스템 (`web/buddle.css` — 단일 진실 공급원)

이전엔 10개 페이지가 각자 `:root`를 인라인 정의했고 이미 폰트 스택이 3종으로
갈라지고 있었다. 이제 **모든 페이지가 `buddle.css` 한 장을 링크**한다.

### 60-30-10
| 비중 | 역할 | 값 |
|---|---|---|
| 60% | paper (바탕) | `--paper:#FBFBFA` |
| 30% | willow-ink (텍스트·구조) | `--ink:#1F2A24` |
| 10% | willow (액센트 — 행동·활성만) | `--willow:#3D8A6B` |

데이터 의미쌍은 채도를 낮춘 `--pos`(성장=버들) / `--caution`(주의=흙빛 클레이,
경보 빨강 아님)만 남겼다 — 구 MTS의 빨강/파랑 이분법은 폐기.

### 타이포그래피
- 디스플레이: **Fraunces** (따뜻한 세리프 — 인간미). 절제해서 사용.
- 본문: **Spline Sans** (정돈된 산세리프 — 고요함).
- 데이터: 같은 Spline Sans + tabular-nums.
- 스케일: 28/22/17/15/13/11.5px (모바일 우선, 1.25 비율).

### 서명 요소 — 가지 실선(branch thread)
`.bd-thread` / `.bd-node`: 콘텐츠 좌측을 따라 흐르는 1px 실선과 작은 잎 노드.
버드나무 가지이자 "사람을 잇는 매질"로서의 buddle을 구조적으로 은유한다 —
장식이 아니라 의미. (현 단계는 토큰·프리미티브로 제공; 페이지별 점진 적용.)

## 프리미티브 (bd-* 클래스)
버튼(`.bd-btn` + `--primary/--ghost/--danger/--block`), 카드(`.bd-card`),
칩(`.bd-chip` + `--on`), 입력(`.bd-input/.bd-textarea`), 토글(`.bd-switch`),
미터(`.bd-meter`), 배지(`.bd-badge`), 하단 네비(`.bd-nav`), 상단바(`.bd-top`),
빈 상태(`.bd-empty`), 스크롤 리빌(`.bd-reveal`).

### 마이크로 인터랙션
- 모든 전이는 `--ease:cubic-bezier(.22,.61,.36,1)` + `--dur:.22s` — 차분하게,
  통통 튀지 않게.
- 스크롤 리빌은 **페일세이프**: 기본은 보임, JS가 동작을 확인할 때만 애니메이션을
  덧입힌다(스크립트가 막혀도 콘텐츠가 사라지지 않음).
- `prefers-reduced-motion`·키보드 포커스 가시성은 토큰 레벨에서 보장(품질 바닥선).

## 공유 자산
| 파일 | 역할 |
|---|---|
| `buddle.css` | 토큰 + 프리미티브 + 레거시 토큰 브리지(구 `--forest/--navy/…`를 버들 팔레트로 재매핑) |
| `buddle.ux.js` | 스크롤 리빌 / 스태거 (점진적 향상) |
| `buddle.security.js` | XSS·CSP·클릭재킹 방어 유틸(`window.sec`) — 페이지 인라인본과 동일 |

## 페이지별 적용 수준
- **완전 재구축** (bd-* 프리미티브 기반): `login.html`(0.05초 첫인상 — 버들
  히어로·단일 CTA), `home-dashboard.html`(MTS 은유 완전 제거 — 페르소나=존재감,
  화제=살아있는 대화), `profile.html`(주권 4권리 화면).
- **토큰 수렴** (인라인 `:root` 제거 → `buddle.css` 링크 + 레거시 브리지 +
  라벤더→버들 치환): feed, chat, compose, inbox, nearby, persona-create,
  persona-select. 마크업·로직은 보존, 팔레트만 버들로 통일.

## 다음 단계 (점진 개선)
각 수렴 페이지를 bd-* 프리미티브로 한 화면씩 완전 재구축하면서 레거시 브리지
의존을 줄여간다. 0019~0021 신규 화면(매칭 기여 시각화·토론 대시보드·주장 AI
대화)은 처음부터 bd-* 위에서 설계한다.
