# buddle 프론트엔드 페이지 구조 설계

> 백엔드 전체 기능 + 기존 화면(persona-select, home-dashboard) 기반.
> 디자인: Sprout(딥 포레스트 #00522d / 민트 #c5e8d6 / 크림 #f7f4ec), MTS 증권앱 레이아웃 차용.
> MTS 매핑 핵심: **종목 = 페르소나**, 지수 = 활발한 분야, 테마 = 핫 주제, 종목순위 = 대화 순위.

---

## 1. 화면 트리 (전체)

> **주 동선(메인 플로우): 홈 → 페르소나 선택 → 대화.**
> "내 활동/설정"은 독립 화면이 아니라 **대화창 우상단 설정 박스**에 통합(위치·선호 언어·페르소나 관리).

```
[비로그인]
 ├─ 0. 온보딩/로그인  (login)              ← POST /v1/auth/signup, /login
 │
[로그인 후 — 하단 네비]
 │
 │   ▣ 주 동선:  홈 ──선택──▶ 페르소나 선택 ──선택──▶ 대화(세션)
 │
 ├─ 1. 홈 대시보드  ✅완성 (home-dashboard) ← GET /v1/feed, /personas, plaza/board
 │     · AI 브리핑 / 활발한 분야 / 나의 페르소나(종목) / 핫 주제 / 대화 순위
 │     · 페르소나(종목) 행 탭 → 바로 그 페르소나 대화로
 │     · 페르소나 더보기 → 2. 페르소나 선택
 │
 ├─ 2. 페르소나 선택  ✅완성 (persona-select) ← GET /v1/personas
 │     · 페르소나 카드 탭 → 3. 대화로 진입
 │     ├─ 2a. 페르소나 생성       (persona-create)  ← POST /v1/personas (위치 통합)
 │     ├─ 2b. 페르소나 상세/수정   (persona-detail)  ← GET/PATCH /v1/personas/{id}
 │     └─ 2c. 근처 사람 매칭       (nearby)          ← GET /v1/proximity/.../nearby
 │           · 매칭 상대 선택 → 그 주제로 대화 세션 열기
 │
 ├─ 3. 대화 (세션)  ★핵심 — 페르소나 선택 후 도착하는 곳
 │     ├─ 3a. 세션 목록   (session-list)   ← GET /v1/personas/{id}/sessions
 │     │       · 주제별 세션 / [+ 새 주제] / [+ 새 주제는 글쓰기로]
 │     └─ 3b. 대화창       (chat)           ← WS dialogue, GET .../sessions/{sid}/messages
 │           · 말풍선(내/페르소나) + [참고 자료] 접이식 + [통합 인사이트]
 │           · ★ 우상단 [설정 박스] ← 내 활동/설정 통합:
 │               · 위치 기반 대화 토글 (기본 ON)
 │               · 선호 언어 (한국어/English)
 │               · 페르소나 관리 (→ 2b 상세/수정)
 │               · 계정/로그아웃            ← GET/PATCH /v1/users/me
 │
 ├─ 4. 글쓰기 (생각→글)  ★핵심 (compose)   ← POST /v1/plaza/posts
 │     · 생각 입력 → 페르소나 다국어 변환 미리보기 → 공개/비공개 → 게시
 │     · 대화/세션에서 "생각 올리기"로도 진입
 │
 ├─ 5. 피드/페이지  (feed-detail)          ← GET /v1/feed, /posts/{id}, comments
 │     ├─ 주제별 글 목록 (topic-feed)
 │     └─ 글 상세 + 댓글  (post-detail)     ← GET/POST /v1/plaza/posts/{id}/comments
 │
 └─ 6. 인박스(전달받은 글)  (inbox)        ← GET /v1/inbox, POST /v1/inbox/{id}/seen

[관리자 — 별도]
 └─ 7. 어드민 대시보드 (admin)  ← /v1/admin/* (모니터·윤리·기술자·지식공간 tick/audit)
```

✅ = 완성. ★ = 다음 제작 우선순위. **"내 활동/설정" 독립 화면 삭제 → 대화창 설정 박스로 통합.**

### 주 동선 상세
```
[홈]  나의 페르소나(종목) 목록에서 페르소나 탭
   │   또는 [페르소나 더보기]
   ▼
[페르소나 선택]  카드 탭 (또는 새 페르소나 생성)
   ▼
[대화 — 세션 목록]  그 페르소나의 주제 세션들
   │   기존 세션 탭 → 대화창 / [+ 새 주제] → 글쓰기 or 빈 대화창
   ▼
[대화창]  메시지 주고받기 + 우상단 설정 박스(위치/언어/페르소나/계정)
```

## 2. 핵심 흐름 ① — 생각→글 (글쓰기, compose)

buddle의 정체성. "글 못 써도 생각만 넣으면 다국어 글이 된다."

```
[1] 페르소나 선택 (누구로 쓸지)
       ▼
[2] 생각 입력 (거친 메모, 짧아도 됨)  ← textarea
       │  "오늘 동네 산책했는데 강가 코스가 좋더라. 같이 할 사람?"
       ▼
[3] 페르소나 변환 미리보기            ← POST /v1/plaza/posts (또는 미리보기 전용)
       │  페르소나 AI가 정제 → content_transformed
       │  ┌─ 한국어 버전 (원문 언어)
       │  └─ English 버전 (자동 번역, post_translations)   ← 다국어 파이프라인
       ▼
[4] 공개 / 비공개 선택               ← visibility 토글 (PUBLIC/PRIVATE)
       │  · 공개: 광장 + 매칭 전달
       │  · 비공개: 본인 + 지식공간(비공개 경계)만
       ▼
[5] 게시                            ← POST 확정
       │  → 매개자 분배(관련도 매칭) → 인박스 전달
       │  → 레이어 B consider_post (선별)
       ▼
[6] 게시 완료 → 홈/피드로
```

화면 요소: 페르소나 칩(상단), 생각 textarea, [변환] 버튼, 변환 결과 2개 언어 카드(탭 전환), 공개/비공개 세그먼트, [게시] 버튼. 변환 중 로딩.

## 3. 핵심 흐름 ② — 대화 (세션, chat)

주제별 세션, GPT/Claude 대화창. 1:1 아님(주제 열림).

```
[세션 목록]  ← GET /v1/personas/{id}/sessions (최근활동순)
  · "동네 산책" (어제) / "AI와 글쓰기" (3일 전) ...
  · [+ 새 주제]
       ▼
[대화창]  ← WS dialogue + GET .../sessions/{sid}/messages
  ┌─────────────────────────────┐
  │ 페르소나 메시지 / 내 메시지 (말풍선)     │
  │ ...                                  │
  │ ┌ [참고 자료] 접이식 (지식공간)         │  ← fetch_context (선택)
  │ └ [통합 인사이트] (있으면)              │  ← include_insights
  ├─────────────────────────────┤
  │ 입력창 + 전송 (session_id 포함)         │
  └─────────────────────────────┘
```

말풍선은 Sprout 톤(내 메시지=포레스트, 페르소나=민트 배경). 참고자료는 대화 흐름 방해 않게 접이식.

| 화면 | 주요 API | 상태 |

| 0 로그인 | POST /v1/auth/signup·login·refresh | 신규 |
| 1 홈 | GET /v1/feed, /personas, /plaza/board | ✅ |
| 2 페르소나 선택 | GET /v1/personas | ✅ |
| 2a 생성 | POST /v1/personas (위치 필드 포함) | 신규 |
| 2b 상세/수정 | GET/PATCH /v1/personas/{id} | 신규 |
| 2c 근처 매칭 | GET /v1/proximity/personas/{id}/nearby | 신규 |
| 3a 세션목록 ★ | GET/POST /v1/personas/{id}/sessions | 신규 |
| 3b 대화창 ★ | WS dialogue, GET .../messages, /context | 신규 |
| 4 글쓰기 ★ | POST /v1/plaza/posts | 신규 |
| 5 피드/글상세 | GET /v1/feed, /posts/{id}, comments | 신규 |
| 6 인박스 | GET /v1/inbox, POST /{id}/seen | 신규 |

## 5. 공통 컴포넌트 (재사용)

- **하단 네비**: 홈 / 대화 / 글쓰기 / 피드 (내 활동 탭 제거 — 설정은 대화창 우상단 박스로). home-dashboard 네비 라벨 갱신 필요
- **페르소나 아바타**: 이름 첫 글자 + Sprout 팔레트 색 (일관 규칙)
- **언어 칩**: 한국어/English/홍콩(街頭小食) 토큰
- **증감 pill**: 상승=빨강(#e8483d) / 하락=파랑(#2f6df0) — MTS 한국 관례
- **설정 박스(대화창 우상단)**: 위치 토글(기본 ON) + 선호 언어 + 페르소나 관리 + 계정/로그아웃. persona-select의 설정 드로어 재사용·확장
- **공개/비공개 세그먼트**, **접이식 참고자료 블록**

## 6. 제작 순서 제안

**주 동선(홈→페르소나→대화) 우선:**
1. **대화(3a 세션 목록 + 3b 대화창)** — 주 동선의 종착점. 우상단 설정 박스(위치/언어/페르소나/계정) 포함. 가장 먼저.
2. **글쓰기(4 compose)** — 정체성 화면. 생각→다국어→공개/비공개→게시. 대화에서 "생각 올리기"로 연결.
3. **페르소나 생성/상세(2a/2b)** — 위치 통합 반영. 설정 박스의 "페르소나 관리"와 연결.
4. **피드/글상세(5)** + **인박스(6)**.
5. 근처 매칭(2c) → 세션 열기 연결, 로그인(0).
6. 어드민(7) 후순위.

각 화면은 단일 HTML(기존 방식) 또는 통합 SPA 중 택. 기존 2개가 단일 HTML이므로 일관되게 단일 HTML로 시작, 이후 통합 가능.

## 7. 기술 메모
- 단일 HTML + 바닐라 JS(기존 persona-select/home-dashboard 방식 유지) → 의존성 0, 바로 열림.
- API 연동: fetch(). 인증은 JWT(Authorization 헤더). WS는 대화창만.
- localStorage 사용 안 함(아티팩트 제약). 상태는 메모리/페이지 이동으로.
- 디자인 토큰 일관: Sprout 색 + Fraunces/Spline Sans 폰트.
